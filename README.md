# あそぴてっく / asopitech 👋

個人開発者として、分散システム・データベース・プログラミング言語・AI 検索基盤にまたがる OSS エコシステムを設計・実装しています。試作は各 Organization として公開し、手応えのあったものをプロダクトや企業向け機能へ育てています。

An independent developer designing and building an OSS ecosystem across distributed systems, databases, programming languages, and AI retrieval. Prototypes are published under dedicated organizations and, when they hold up, grown into products and enterprise features.

## 🚧 今つくっているもの / What I'm building right now

直近のコミット日時が入ったバッジ付きで、実際に動いているリポジトリだけを載せています。/ Badged with actual last-commit dates — only repositories with real recent activity are listed here.

- **[Alopex DB](https://github.com/alopex-db/alopex)** ![Last commit](https://img.shields.io/github/last-commit/alopex-db/alopex?label=last%20commit) — SQL・ベクトル検索(HNSW)・列指向を1つのRustエンジンに統合。embeddedから分散クラスタまで同じコアでスケール。
  A unified Rust engine combining SQL, Vector Search (HNSW), and columnar storage — scaling from embedded to distributed on the same core.
- **[LAMINARIA](https://github.com/asopitech-labs/laminaria-rust-nim-toolchain)** ![Last commit](https://img.shields.io/github/last-commit/asopitech-labs/laminaria-rust-nim-toolchain?label=last%20commit) — RustとNimを1つの計算グラフとして扱う統合ツールチェーン。
  A unified toolchain modeling Rust and Nim as one computational graph.
- **[NAVISOMA](https://github.com/asopitech-labs/navisoma-nim-container-toolchain)** ![Last commit](https://img.shields.io/github/last-commit/asopitech-labs/navisoma-nim-container-toolchain?label=last%20commit) — Nim製のクロスプラットフォームコンテナツールチェーン（Compose / OCIをネイティブ実装）。
  A cross-platform container toolchain in Nim with native Compose/OCI implementations.
- **[Noetide](https://github.com/asopitech-labs/noetide-research-planning-engine)** ![Last commit](https://img.shields.io/github/last-commit/asopitech-labs/noetide-research-planning-engine?label=last%20commit) — 計画を研究課題に、検証結果を意思決定に変える継続的リサーチ・プランニングエンジン。
  A continuous research and planning engine turning plans into research questions and evidence into decisions.
- **[Global Executables](https://github.com/asopitech-labs/global-executables)** ![Last commit](https://img.shields.io/github/last-commit/asopitech-labs/global-executables?label=last%20commit) — パッケージエコシステム横断で実行ファイル名を収集し、MCP経由でAIエージェントに公開するデータセット。
  A cross-ecosystem dataset of executable names, exposed to AI agents via MCP.
